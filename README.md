# Лабораторная работа 1: Сбор параметров ОС

## Описание программы
Скрипт определяет, в какой ОС он запускается (Windows, Linux, MacOS), собирает параметры текущей ОС и записывает их в файл формата JSON. В скрипте используются модули 'os', 'sys', 'platform' 'psutil', 'json'.

Данные собираются в виде словаря. Результат выполнения скрипта записывается в JSON-файл.
С помощью **'with open'** открываем (создаем) файл и с помощью модуля **'json'** (функция **'json.dump'**) записываем словарь в созданный файл. Благодаря **'with open'** файл автоматически закрывается после выполнения программы.

## Параметры
С помощью модулей **'os'**, **'sys'**, **'platform'** и **'psutil'** скрипт собирает следующие данные:
* Детали ОС (на которой запущен);
* Информацию об оболочке командной строки;
* Информацию о зарядке ноутбука;
* Параметры CPU:
  * Архитектура,
  * Модель,
  * Доступные ядра;
* Параметры RAM
  * Общая память,
  * Доступная память,
  * Использованная память;
* Параметры диска, с которого запущен скрипт
  * Общая память,
  * Свободная память;
* Информацию о сети
  * Сколько Мб отправлено компьютером,
  * Сколько Мб получено компьютером;
* Информацию о пользователе:
  * Текущая директория,
  * Список пользователей,
  * Имя пользователя,
  * Сетевое имя компьютера,
  * Путь к домашней папке пользователя,
  * Системная переменная окружения 'PATH');
* Список запущенных процессов (от 100 Мб оперативной памяти, чтобы их было не слишком много);
* Параметры Python
  * Версия,
  * Компилятор,
  * Реализация;
* ID текущего процесса.

Внешний модуль **'psutil'** используется для сбора информации об оперативной памяти, диске, сети и запущенных процессах. Он выбран, потому что встроенные модули не предоставляют информацию об этих компонентах ОС. Также модуль **'psutil'** кроссплатформенный, простой в использовании и имеет высокую скорость работы.

Для установки модуля необходимо ввести в командную строку команду: **'pip install psutil'**.
